# Security policy

## Supported versions

FixtureSmith has not published its first stable release. Security fixes target
the latest released minor line once packages are available on npm.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting for this repository:

`Security` → `Advisories` → `Report a vulnerability`

Include affected versions, impact, reproduction steps, and any suggested
mitigation. Do not access data or systems you do not own while investigating.
Maintainers will acknowledge a complete report as soon as practical, coordinate
a fix and disclosure, and credit reporters who wish to be named.
