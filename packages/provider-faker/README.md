# @fixturesmith/provider-faker

Faker-backed primitive provider for FixtureSmith.

`@fixturesmith/zod` wires this provider automatically. Install it directly when
constructing the schema-neutral engine or extending provider behavior.

See the [FixtureSmith provider guide](https://github.com/sykes10/FixtureSmith/blob/main/docs/providers.md)
for the provider contract.
