# Contributing

See the repository [CONTRIBUTING.md](https://github.com/sykes10/FixtureSmith/blob/main/CONTRIBUTING.md)
for local setup, quality gates, changesets, and pull-request expectations.

Architecture work should begin with the [domain documentation](./README.md) and
the accepted [decision records](./decisions/README.md). New schema support must
update the compatibility matrix and include validation, determinism, negative,
and type coverage.
